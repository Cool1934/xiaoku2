# My Music Player

一个精美的本地音乐播放器，可直接部署到 GitHub Pages。

## 使用方式

1. 把你的 `.mp3` 文件放进 `music/` 文件夹。
2. 打开 `app.js`，在 `MUSIC_FILES` 数组里按格式添加歌曲信息：
   ```js
   { file: 'music/你的歌.mp3', title: '歌名', artist: '歌手' }
   ```
3. 将整个仓库 push 到 GitHub，开启 GitHub Pages 即可访问。

## 功能

- 播放 / 暂停、上一首 / 下一首、随机、单曲循环
- 进度条拖拽 + 实时时间显示、音量调节
- 键盘快捷键：`空格` 播放暂停，`←` `→` 切歌
- 旋转黑胶唱片动画（播放时旋转）
- 深色玻璃拟态 UI，自适应移动端

## 关于 25MB 限制

GitHub 单文件建议 ≤50MB，仓库总大小建议控制在 25MB 以内，
约可放 4-5 首普通码率 mp3。如需更多歌曲可压为 128kbps。
