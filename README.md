# My Music Player

一个可直接部署到 **GitHub Pages** 的精美本地音乐播放器（深色玻璃拟态 UI + 旋转黑胶）。

## 功能
- 播放 / 暂停、上一首 / 下一首、随机、单曲循环
- 进度条拖拽、音量调节、键盘快捷键（空格 / ← →）
- 🔍 **搜索播放列表**（按歌曲名 + 歌手名实时过滤）
- 🎶 **滚动歌词**：支持内嵌 `lyric` 或外部 `.lrc` 文件，当前行高亮 + 自动滚动居中 + **点击歌词行跳转到对应时间**
- ⚡ **先缓冲加载、再自动播放**：从根上解决"点击卡住不播 / 切歌卡一会再播"
  - `preload="auto"` 全量预加载 + `audio.load()` 切歌即触发解码器
  - 缓冲守卫：数据未就绪时显示"加载中/缓冲中…"并等待，就绪后自动开播
  - `onwaiting/onplaying` 状态切换 + `onerror` 自动跳下一首
- 📊 **缓冲可视化**
  - 顶部细进度条：加载/缓冲中自动滑出，显示 `加载中 35%`，100% 自动收起
  - 进度条背景三段式：已播 / 已缓冲 / 未缓冲
  - 常驻文字 `已缓冲 2:15 / 3:40`（无需悬停）+ 悬停 tooltip
- 📌 **自适应预加载**：每 4 秒评估缓冲区领先量
  - 网络慢、缓冲跟不上 → 自动降级为"流式缓冲"（按需边播边缓冲）
  - 网络恢复、缓冲充裕 → 自动恢复"全量预加载"
- 🎚️ **预加载模式手动开关**（播放器底部）：`自动` / `全量` / `流式`，点击即切换，带状态提示文字
- 📢 **状态提示**：加载中 / 缓冲中 / 网络较慢已切换流式 / 音频加载失败跳过… 等实时反馈

## 使用方式
1. 把音乐文件放进 `music/` 目录。
2. 打开 `app.js`，在 `MUSIC_FILES` 里按格式加歌：
   ```js
   { file: 'music/你的歌.mp3', title: '歌名', artist: '歌手' }
   ```
3. （可选）加歌词：
   - 内嵌：`{ ..., lyric: '[00:00]前奏...\n[00:12]第一句歌词' }`
   - 外部：`{ ..., lyricFile: 'music/你的歌.lrc' }`（`.lrc` 为 `[mm:ss]文本` 格式）
4. push 到 GitHub 仓库。
5. **Settings → Pages → Source 选 `Deploy from a branch` → Branch 选 `main` / `root` → Save**。
6. 访问 `https://你的用户名.github.io/仓库名` 即可。

## 关于 25MB 限制
整个播放器代码（html/css/js + README）仅约 24KB，远小于 25MB。音乐文件由你自行放入 `music/`，不计入代码体积；若希望"代码+部分音乐"总包 ≤25MB，只要 `music/` 内文件总大小控制在约 24.9MB 内即可（建议 128–192kbps 以放入更多歌曲）。
